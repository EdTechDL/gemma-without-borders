# Demo video (Remotion)

A 120-second submission video assembled from real, scripted gameplay footage.
The edit follows `docs/DEMO-SCRIPT.md`, with caption cards carrying the
narration lines.

## Pipeline

1. **Footage** — `tools/capture.py` drives the running app with Playwright and
   records two continuous sessions (desktop 1920x1080, phone 430x932), logging
   per-beat timestamps the composition slices against.
   - With Ollama + Gemma installed, footage shows the real model.
   - Without it, `tools/fake_ollama.py` serves canned, correctly-shaped
     responses on :11434 so every AI screen still renders fully.
2. **Assets** — drop the recordings and music into `public/`:
   `desktop.webm`, `phone.webm`, plus `nexus-theme.mp3`, `onboarding.mp3`,
   `correct.mp3` copied from `../static/audio/`.
3. **Composition** — `src/Demo.tsx`: scene list with source timestamps,
   playback rates, and captions. Title, hook, and closing cards use the
   game's palette and type treatment.
4. **Render**:

   ```bash
   npm install
   npx remotion render src/index.ts gemma-demo out/gemma-monsters-demo.mp4
   ```

   Set `REMOTION_BROWSER=/path/to/chromium` to use an existing browser
   binary instead of letting Remotion download one.

`public/` and `out/` are gitignored: footage is regenerated by the capture
script and the audio is copied from `../static/audio/`.
